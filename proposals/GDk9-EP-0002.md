# GDk9-EP-0002: Grammar-Controlled Transition Tables

Status: Draft

## Summary

Move the v1.0.0 transition table into the machine-readable grammar so the grammar is the canonical runtime control surface.

## Motivation

Hardcoded transition tables make standards drift harder to detect. A grammar-controlled table keeps documentation, tests, and runtime behavior anchored to the same artifact.

## Specification Impact

- `grammar/gdk9-v1.0.0.yaml` must include `transitions`.
- Transition entries must identify `next` state and `action`.
- Transition compilation must reject unknown states, unknown actions, and undeclared event classes.

## Runtime Impact

KeySuite generates transition tables from YAML when a `transitions` section is present.

## Conformance Impact

Tests must prove that malformed transition rules fail before runtime execution.
