# GDk9-EP-0003: Public Release Conformance Harness

Status: Draft

## Summary

Define the minimum public release harness for GDk9 and KeySuite repositories.

## Required Checks

- `pytest`
- `make release-check`
- CLI example output: `CC→33`
- version manifest review
- generated artifact cleanup

## Documentation Impact

Release docs must identify the current GDk9 standard version, KeySuite runtime version, grammar version, and test evidence.

## Repository Impact

The release tree should include `README.md`, `LICENSE`, `CONTRIBUTING.md`, `CONTRIBUTORS.md`, `docs/`, `site/`, `standards/`, `grammar/`, `reference/`, `tests/`, and `version/current.txt`.
