# Contributors

GDk9 and KeySuite are maintained as a standards stack plus a reference runtime.

## Maintainers

- GDk9 project maintainers

## Contribution Rules

Contributors must preserve deterministic execution, explicit symbol jurisdiction, commit-only output, and pure reduction. Standards changes require a GDk9 Enhancement Proposal before they are represented as normative.

## Recognition

Add contributors here after accepted standards proposals, runtime patches, conformance tests, documentation improvements, governance work, or release engineering changes.
